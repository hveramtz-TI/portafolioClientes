# HU-032 — Total referencial del carrito

**Épica:** Solicitudes
**Prioridad:** Media
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como visitante, quiero ver un total referencial de los servicios seleccionados, para tener una idea del valor.

## Criterios de Aceptación

- [ ] Se muestra un `Total referencial` calculado como la suma de los valores aproximados seleccionados.
- [ ] Se aclara que no es una cotización definitiva.
- [ ] El total se actualiza al agregar o quitar servicios del carrito.
