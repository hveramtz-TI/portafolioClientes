# HU-011 — Eliminar empresa (bloqueo si tiene clientes asociados)

**Épica:** Clientes y empresas
**Prioridad:** Media
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero eliminar una empresa, para limpiar registros que ya no necesito, siempre que no tenga clientes asociados.

## Criterios de Aceptación

- [ ] Si la empresa no tiene clientes asociados, puede eliminarse definitivamente.
- [ ] Si la empresa tiene clientes asociados, se impide la eliminación.
- [ ] Al intentar eliminar una empresa con clientes, el sistema indica qué clientes están vinculados.
- [ ] Primero deben desvincularse o reasignarse los clientes; luego se permite eliminar.
- [ ] No se eliminan clientes automáticamente.
