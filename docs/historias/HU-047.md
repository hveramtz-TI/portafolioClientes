## Descripción

Como usuario, quiero registrar fechas de inicio y término, y notas, en una orden, para tener seguimiento temporal.

## Criterios de Aceptación

- [ ] La fecha de creación se registra automáticamente.
- [ ] La fecha de inicio es opcional; puede registrarse al pasar a `En progreso` o manualmente.
- [ ] La fecha de término es opcional; puede registrarse al pasar a `Completada` o manualmente.
- [ ] La orden tiene un campo de notas o descripción.
