# HU-006 — Eliminar definitivamente cliente con registros relacionados

**Épica:** Clientes y empresas
**Prioridad:** Alta
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero eliminar definitivamente un cliente y todos sus registros relacionados, para quitarlo por completo del sistema.

## Criterios de Aceptación

- [ ] El modal de eliminación permite elegir "eliminar definitivamente".
- [ ] Se eliminan el cliente y todos sus registros relacionados (órdenes, solicitudes vinculadas, etc.).
- [ ] Se advierte que la acción es irreversible.
- [ ] Se solicita confirmación antes de ejecutar.

## Notas / Dudas

- Debe definirse en SDD el alcance exacto de "registros relacionados" y si se conservan órdenes históricas.
