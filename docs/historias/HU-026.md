# HU-026 — Configurar contacto público explícito

**Épica:** Perfil público
**Prioridad:** Media
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero configurar explícitamente qué datos de contacto se muestran en mi página pública, para no exponer datos privados sin querer.

## Criterios de Aceptación

- [ ] El contacto público se configura explícitamente.
- [ ] No se exponen automáticamente los datos privados del registro.
- [ ] Se puede configurar email, teléfono y/o redes sociales.
- [ ] Los datos configurados se muestran en la página pública.
