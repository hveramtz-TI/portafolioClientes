# HU-056 — Generar y descargar PDF de portafolio (plantilla TMC)

**Épica:** Documento de Portafolio (PDF)
**Prioridad:** Alta
**Estado:** Pendiente
**Fecha:** 2026-09-07

## Descripción

Como **freelancer con cuenta en TMC**, quiero **generar y descargar un PDF de portafolio** desde mis datos de trabajo para **adjuntarlo a mi CV** como evidencia profesional actualizada.

## Criterios de Aceptación

- [ ] El usuario autenticado puede iniciar la generación del PDF desde su cuenta.
- [ ] El PDF se entrega como **descarga** (sin link público permanente).
- [ ] El contenido se construye **solo con datos del usuario autenticado**.
- [ ] El PDF usa la **plantilla TMC fija**: identidad visual del producto, sin configuración ni marca personal del usuario.
- [ ] No existe editor de contenido, diseño ni curado manual de secciones.

## Notas / Dudas

- El HOW técnico (librería/generación server-side vs cliente) se define en SDD design (`planning5.md`).
- Dependencia: requiere órdenes con snapshot de servicios (HU-042+, HU-044) implementadas (RK4 en planning5).
- Pendientes P1–P4 de planning5 pueden afectar la plantilla final.
