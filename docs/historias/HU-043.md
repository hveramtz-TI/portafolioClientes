# HU-043 — Transicionar estado de orden

**Épica:** Órdenes de trabajo
**Prioridad:** Alta
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero cambiar el estado de una orden, para reflejar su avance.

## Criterios de Aceptación

- [ ] Estados: `Pendiente`, `En progreso`, `Completada` y `Cancelada`.
- [ ] Transiciones permitidas: `Pendiente → En progreso → Completada` o `Cancelada`.
- [ ] `Completada` y `Cancelada` son estados finales.
- [ ] No se puede completar una orden cancelada.
