# HU-014 — Editar rubro

**Épica:** Rubros, categorías y servicios
**Prioridad:** Media
**Estado:** Aprobada
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero editar el nombre de un rubro de mi catálogo personal, para mantener actualizada mi organización de servicios.

## Criterios de Aceptación

- [ ] Se puede modificar el nombre de un rubro (base o fork personal).
- [ ] Los cambios en rubro base se reflejan en categorías/servicios asociados y en forks de otros usuarios (si no tienen override).
- [ ] Se puede editar tanto un rubro precargado (base) como uno propio (fork personal).
- [ ] Al editar un fork personal (`user_catalog_items`), solo afecta la copia del usuario, no la base ni otros usuarios.
- [ ] El nuevo nombre mantiene unicidad global (`name` unique en `rubros` para base; `user_id + base_rubro_id` unique en forks).

## Notas / Dudas

- Modelo híbrido: editar base → propaga a forks sin override. Editar fork → aisla cambios. Unicidad validada en Request. Rate limiting: evaluar en SDD-design.
