# HU-023 — Eliminar o desactivar servicio (según historial de uso)

**Épica:** Rubros, categorías y servicios
**Prioridad:** Media
**Estado:** Aprobada
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero eliminar o desactivar un servicio de mi catálogo personal, para limpiarlo sin afectar órdenes históricas.

## Criterios de Aceptación

- [ ] Un servicio sin historial de uso en órdenes puede eliminarse definitivamente (`forceDelete()`).
- [ ] Un servicio con historial de uso en órdenes se desactiva (`status = 'desactivado'`); la orden conserva su copia histórica inmutable en `order_services`.
- [ ] El servicio desactivado no se muestra en perfil público ni se ofrece en nuevas solicitudes (scope `whereStatus('activo')`).
- [ ] Aplica tanto a servicio base como a fork personal (`user_catalog_items`).
- [ ] El servicio desactivado puede reactivarse (`status = 'activo'`).

## Notas / Dudas

- Modelo híbrido: `status` enum (`activo`, `desactivado`) + `SoftDeletes` trait. **Decisión en tiempo real:** al intentar eliminar → check `order_services.count()`; si > 0 → desactivar; si = 0 → `forceDelete()`. Copia histórica en `order_services` siempre intacta.
