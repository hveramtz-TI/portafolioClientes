# HU-023 — Eliminar o desactivar servicio (según historial de uso)

**Épica:** Rubros, categorías y servicios
**Prioridad:** Media
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero eliminar o desactivar un servicio, para limpiar mi catálogo sin afectar órdenes históricas.

## Criterios de Aceptación

- [ ] Un servicio sin historial de uso en órdenes puede eliminarse definitivamente.
- [ ] Un servicio con historial de uso se desactiva (la orden ya conserva su copia, pero el catálogo lo oculta del perfil público).
- [ ] El servicio desactivado no se ofrece en nuevas solicitudes.
