# HU-042 — Crear orden para cliente (inicia Pendiente, vincula solicitud)

**Épica:** Órdenes de trabajo
**Prioridad:** Alta
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero crear una orden de trabajo para un cliente, para gestionar el trabajo a realizar.

## Criterios de Aceptación

- [ ] Se puede crear una orden para un cliente.
- [ ] La orden inicia en estado `Pendiente`.
- [ ] Si proviene de una solicitud, conserva el vínculo con la solicitud y el cliente.
- [ ] Se registra la fecha de creación automáticamente.
