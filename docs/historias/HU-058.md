# HU-058 — Anonimización del cliente con rubro visible

**Épica:** Documento de Portafolio (PDF)
**Prioridad:** Alta
**Estado:** Pendiente
**Fecha:** 2026-09-07

## Descripción

Como **freelancer**, quiero que el PDF **nunca revele clientes reales** pero sí el rubro de su proyecto, para **mostrar alcance profesional sin exponer información sensible** de mis contratos.

## Criterios de Aceptación

- [ ] El PDF no muestra nombre del cliente ni de la empresa.
- [ ] El PDF no muestra RUT, email, teléfono, dirección ni ningún dato de contacto.
- [ ] Cada proyecto se identifica de forma anónima con el patrón aprobado: **`Proyecto {tipo de trabajo} de una empresa destacada en el rubro {rubro}`** (ej. "Proyecto inmobiliaria de una empresa destacada en el rubro Construcción").
- [ ] El **rubro sí se muestra** (es la señal de industria del trabajo realizado).
- [ ] El rubro proviene del catálogo snapshot/asociado a los servicios de la orden.

## Notas / Dudas

- P1 de planning5: ¿qué rubro mostrar si una orden mezcla servicios de rubros distintos?
- La redacción exacta del patrón (con/sin empresa, plural "empresas") se pule en SDD.
