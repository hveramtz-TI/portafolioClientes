# HU-013 — Crear rubro

**Épica:** Rubros, categorías y servicios
**Prioridad:** Alta
**Estado:** Aprobada
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero crear un rubro en mi catálogo personal, para organizar mis servicios por área profesional.

## Criterios de Aceptación

- [ ] Se puede crear un rubro con un nombre único en el catálogo base global.
- [ ] El nombre se expresa en lenguaje natural.
- [ ] El rubro se muestra disponible en el catálogo base para asociarle categorías; al seleccionarlo, se crea un fork personal en `user_catalog_items`.
- [ ] El nombre es único a nivel global (catálogo base).
- [ ] El usuario propietario del fork puede editar/desactivar/eliminar su copia sin afectar la base.

## Notas / Dudas

- Modelo híbrido: rubro se crea en catálogo base global (seeders o admin). Usuario accede via fork personal (`user_catalog_items`). Unicidad: `name` unique en tabla `rubros`.
- **Consideración diseño:** Evaluar rate limiting en creación de rubros (ej: 10/min por usuario) para prevenir abuso/spam. Definir en SDD-design.
