# HU-013 — Crear rubro

**Épica:** Rubros, categorías y servicios
**Prioridad:** Alta
**Estado:** Aprobada
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero crear un rubro en mi catálogo personal, para organizar mis servicios por área profesional.

## Criterios de Aceptación

- [ ] El usuario puede crear un rubro en su catálogo personal/fork.
- [ ] El nombre se expresa en lenguaje natural.
- [ ] El rubro personal queda disponible para asociarle categorías dentro del fork del usuario.
- [ ] La creación de rubros base pertenece a HU-024 (seeders/proceso administrativo), no a esta HU.
- [ ] El nombre es único dentro del catálogo personal del usuario, según validación de aplicación.
- [ ] El usuario propietario del fork puede editar/desactivar/eliminar su copia sin afectar la base.

## Notas / Dudas

- El usuario crea el rubro directamente en su catálogo personal (`user_catalog_items`, `base_id = null`); no crea registros globales. La creación del catálogo base se realiza mediante seeders/proceso administrativo en HU-024.
- **Implementación:** Los detalles no definidos quedan TBD para SDD.
