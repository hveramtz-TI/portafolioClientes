# HU-002 — Crear cliente

**Épica:** Clientes y empresas
**Prioridad:** Alta
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero crear un cliente con sus datos obligatorios, para registrarlo en el sistema.

## Criterios de Aceptación

- [ ] El formulario solicita nombre, RUT, teléfono y email como obligatorios.
- [ ] El formulario permite apellido, dirección, empresa asociada, notas y sitio web como opcionales.
- [ ] El RUT y el email se validan en formato.
- [ ] El cliente se crea en estado `Activo`.
- [ ] Se muestra error y se cancela el guardado si los campos obligatorios están vacíos o inválidos.

## Notas / Dudas

- La validación de duplicados RUT + empresa se trata en HU-003.
