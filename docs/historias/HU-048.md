# HU-048 — Total automático de la orden

**Épica:** Órdenes de trabajo
**Prioridad:** Alta
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero que el total de una orden se calcule automáticamente, para tener un valor consistente.

## Criterios de Aceptación

- [ ] El total se calcula sumando los servicios de la orden.
- [ ] No existe un valor manual independiente por orden.
- [ ] El total se actualiza al agregar, editar o eliminar servicios.
