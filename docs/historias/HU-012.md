# HU-012 — Asociar/desasociar cliente a empresa

**Épica:** Clientes y empresas
**Prioridad:** Alta
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero asociar o desasociar un cliente a una empresa, para mantener la relación cliente-empresa actualizada.

## Criterios de Aceptación

- [ ] Un cliente puede asociarse como máximo a una empresa.
- [ ] Un cliente puede existir sin empresa asociada.
- [ ] La empresa puede tener múltiples clientes.
- [ ] Se puede desasociar un cliente de su empresa.
- [ ] Al asociar/desasociar se revalida la unicidad RUT + empresa.
