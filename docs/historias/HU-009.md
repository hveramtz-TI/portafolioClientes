# HU-009 — Crear empresa

**Épica:** Clientes y empresas
**Prioridad:** Alta
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero crear una empresa como registro independiente, para poder asociarle clientes.

## Criterios de Aceptación

- [ ] El formulario solicita nombre, RUT, email y teléfono como obligatorios.
- [ ] El formulario permite dirección y sitio web como opcionales.
- [ ] El RUT y el email se validan en formato.
- [ ] La empresa se crea y queda disponible para asociar a clientes.

## Notas / Dudas

- La validación de duplicados de empresa se define en SDD (recomendado: RUT único).
