# HU-022 — Editar servicio (título, descripción, valor)

**Épica:** Rubros, categorías y servicios
**Prioridad:** Alta
**Estado:** Aprobada
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero editar los datos de un servicio de mi catálogo personal, para mantener actualizado mi catálogo.

## Criterios de Aceptación

- [ ] Se puede modificar título, descripción y valor (base o fork personal).
- [ ] Se puede modificar la categoría padre y las etiquetas técnicas (JSON array).
- [ ] El cambio de valor no afecta las órdenes históricas (conservan su copia en `order_services`).
- [ ] Al editar un fork personal (`user_catalog_items`), solo afecta la copia del usuario, no la base ni otros usuarios.
- [ ] El nuevo título mantiene unicidad dentro de la categoría: `categoria_id` para base y `parent_fork_id` para un fork personal.
- [ ] Cambiar categoría padre mueve el servicio (validando unicidad en nueva categoría).

## Notas / Dudas

- Editar base → propaga a forks sin override. Editar fork → aísla cambios. **Copia histórica inmutable** en `order_services` (título + valor al momento de agregar). En base, el movimiento actualiza `categoria_id`; en fork, mueve `parent_fork_id` al fork de categoría destino. La identidad del fork y el título visible se validan por separado a nivel de aplicación.
