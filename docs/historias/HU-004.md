# HU-004 — Editar cliente

**Épica:** Clientes y empresas
**Prioridad:** Alta
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero editar los datos de un cliente existente, para mantener su información actualizada.

## Criterios de Aceptación

- [ ] Se puede modificar nombre, RUT, teléfono y email.
- [ ] Se puede modificar apellido, dirección, empresa asociada, notas y sitio web.
- [ ] Se revalidan formato de RUT y email, y la unicidad RUT + empresa.
- [ ] Los cambios se guardan y se reflejan en el listado.
