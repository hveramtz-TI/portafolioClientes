# HU-045 — Editar/eliminar servicio dentro de la orden

**Épica:** Órdenes de trabajo
**Prioridad:** Alta
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero editar o eliminar los servicios de una orden mientras esté editable, para ajustar el trabajo.

## Criterios de Aceptación

- [ ] Se puede editar la información de un servicio agregado a la orden.
- [ ] Se puede eliminar un servicio de la orden.
- [ ] Solo es posible mientras la orden esté editable (`Pendiente` o `En progreso`).
