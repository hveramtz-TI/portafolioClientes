**Épica:** Rubros, categorías y servicios
**Prioridad:** Alta

**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero crear un servicio dentro de una categoría, para ofrecerlo a mis clientes.

## Criterios de Aceptación

- [ ] El servicio tiene título obligatorio.
- [ ] El servicio tiene descripción opcional.
- [ ] El servicio tiene valor aproximado simple en CLP por proyecto.
- [ ] El servicio se asocia a una categoría.
- [ ] Puede tener etiquetas técnicas opcionales (Frontend, Backend, Fullstack, etc.).
