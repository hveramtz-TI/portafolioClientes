# HU-021 — Crear servicio

**Épica:** Rubros, categorías y servicios
**Prioridad:** Alta
**Estado:** Aprobada
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero crear un servicio dentro de una categoría de mi catálogo personal, para ofrecerlo a mis clientes.

## Criterios de Aceptación

- [ ] El servicio tiene título obligatorio.
- [ ] El servicio tiene descripción opcional.
- [ ] El servicio tiene valor aproximado simple en CLP por proyecto (entero, ≥ 0).
- [ ] El servicio se asocia a una categoría (base o fork personal).
- [ ] Puede tener etiquetas técnicas opcionales (JSON array: `['frontend', 'backend', 'fullstack', 'devops', 'mobile']`).
- [ ] El título es único dentro de la categoría padre (`categoria_id + title` unique en tabla `services`).
- [ ] Si la categoría es un fork personal, el servicio se crea en el fork del usuario (`user_catalog_items`).

## Notas / Dudas

- Modelo híbrido: servicio en catálogo base global (`services` table) o fork personal (`user_catalog_items`). Unicidad: `categoria_id + title` unique. FK `categoria_id` → `categorias.id`. Campo `tags` JSON nullable. Valor en CLP entero (centavos o pesos).
- **Copia histórica:** al agregar a orden, se guarda snapshot título + valor en `order_services`.
