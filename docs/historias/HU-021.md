# HU-021 — Crear servicio

**Épica:** Rubros, categorías y servicios
**Prioridad:** Alta
**Estado:** Aprobada
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero crear un servicio dentro de una categoría de mi catálogo personal, para ofrecerlo a mis clientes.

## Criterios de Aceptación

- [ ] El servicio tiene título obligatorio.
- [ ] El servicio tiene descripción opcional.
- [ ] El servicio tiene valor aproximado simple en CLP por proyecto (entero, ≥ 0).
- [ ] El usuario puede crear el servicio dentro de una categoría de su catálogo personal/fork.
- [ ] Puede tener etiquetas técnicas opcionales (JSON array: `['frontend', 'backend', 'fullstack', 'devops', 'mobile']`).
- [ ] El título es único dentro de la categoría padre del catálogo personal.
- [ ] El servicio se crea como item personal en `user_catalog_items` (`base_id = null`), con su categoría fork como padre.
- [ ] La creación de servicios base pertenece a HU-024 (seeders/proceso administrativo), no a esta HU.

## Notas / Dudas

- El usuario no crea servicios globales: crea servicios personales en `user_catalog_items`, bajo una categoría fork. Los servicios base se cargan mediante seeders/proceso administrativo en HU-024. Campo `tags` JSON nullable. Valor en CLP entero (pesos).
- **Copia histórica:** al agregar a orden, se guarda snapshot título + valor en `order_services`.
