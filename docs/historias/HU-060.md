# HU-060 — Servicios del snapshot con estado general

**Épica:** Documento de Portafolio (PDF)
**Prioridad:** Media
**Estado:** Pendiente
**Fecha:** 2026-09-07

## Descripción

Como **freelancer**, quiero que cada proyecto del PDF liste **los servicios tal como se contrataron** (nombre y valor del snapshot) junto con el estado general del proyecto, para que el portafolio refleje **trabajo real ejecutado** y no el catálogo actual.

## Criterios de Aceptación

- [ ] Los servicios se listan **nominados** (título visible) — regla obligatoria del producto.
- [ ] El título y el valor provienen del **snapshot histórico** de `order_services` (copia tomada al agregar el servicio a la orden, HU-044), no del catálogo vigente.
- [ ] Si el servicio fue renombrado o re-valorado después en el catálogo, el PDF muestra el valor histórico de la orden.
- [ ] El estado general del proyecto (`Completada` / `En progreso`) se muestra junto a sus servicios.

## Notas / Dudas

- Esta HU depende del snapshot inmutable de planning3 D10 / HU-044: si el snapshot no está implementado, esta HU no puede cerrarse.
