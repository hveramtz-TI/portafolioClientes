# HU-020 — Eliminar definitivamente categoría sin relaciones

**Épica:** Rubros, categorías y servicios
**Prioridad:** Media
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero eliminar definitivamente una categoría que no tiene servicios ni historial, para limpiar mi catálogo.

## Criterios de Aceptación

- [ ] Una categoría sin servicios ni historial puede eliminarse definitivamente.
- [ ] Si tiene servicios u órdenes relacionadas, no se permite la eliminación definitiva (debe desactivarse).
