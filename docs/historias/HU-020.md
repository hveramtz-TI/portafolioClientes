# HU-020 — Eliminar definitivamente categoría sin relaciones

**Épica:** Rubros, categorías y servicios
**Prioridad:** Media
**Estado:** Aprobada
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero eliminar definitivamente una categoría de mi catálogo personal que no tiene servicios ni historial, para limpiarlo.

## Criterios de Aceptación

- [ ] Una categoría base sin relaciones ni forks puede eliminarse definitivamente (`forceDelete()`); un fork puede eliminarse recursivamente aunque tenga hijos.
- [ ] Si tiene servicios u órdenes relacionadas, no se permite la eliminación definitiva → debe desactivarse (HU-019).
- [ ] El fork personal puede eliminarse mediante `/api/user-catalog/...`, incluso con hijos, eliminando recursivamente el subárbol; la base queda intacta.
- [ ] La base solo puede eliminarse mediante admin/seeder y únicamente si no tiene forks ni relaciones.

## Notas / Dudas

- Para la base, `forceDelete()` requiere validar ausencia de relaciones y forks. Para un fork, la eliminación recursiva está permitida aunque tenga hijos.
