# HU-005 — Desactivar cliente (conserva datos)

**Épica:** Clientes y empresas
**Prioridad:** Alta
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero desactivar un cliente desde un modal, para dejar de usarlo activamente sin perder sus datos relacionados.

## Criterios de Aceptación

- [ ] Al eliminar un cliente se muestra un modal con dos opciones: eliminar definitivamente o desactivar.
- [ ] La opción "desactivar" cambia el estado a `Desactivado`.
- [ ] El cliente desactivado conserva sus datos y registros relacionados.
- [ ] El cliente desactivado deja de mostrarse en el listado por defecto.
- [ ] El cliente desactivado sigue bloqueando duplicados RUT + empresa.

## Notas / Dudas

- La eliminación definitiva se trata en HU-006.
