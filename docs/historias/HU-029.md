# HU-029 — Página pública estilo delivery (rubro→categoría→servicio)

**Épica:** Perfil público
**Prioridad:** Media
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como visitante, quiero navegar los rubros, categorías y servicios de forma similar a una app de delivery, para encontrar y seleccionar servicios fácilmente.

## Criterios de Aceptación

- [ ] El primer rubro aparece seleccionado automáticamente.
- [ ] La primera categoría de ese rubro aparece seleccionada automáticamente.
- [ ] Los servicios de esa categoría se muestran de inmediato.
- [ ] El visitante puede navegar entre rubros, categorías y servicios.
