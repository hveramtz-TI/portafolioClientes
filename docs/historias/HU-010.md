# HU-010 — Editar empresa

**Épica:** Clientes y empresas
**Prioridad:** Media
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero editar los datos de una empresa existente, para mantener su información actualizada.

## Criterios de Aceptación

- [ ] Se puede modificar nombre, RUT, email y teléfono.
- [ ] Se puede modificar dirección y sitio web.
- [ ] Se revalidan formato de RUT y email.
- [ ] Los cambios se guardan y se reflejan en las asociaciones con clientes.
