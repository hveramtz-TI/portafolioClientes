# HU-016 — Eliminar definitivamente rubro sin relaciones

**Épica:** Rubros, categorías y servicios
**Prioridad:** Media
**Estado:** Aprobada
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero eliminar definitivamente un rubro de mi catálogo personal que no tiene relaciones, para limpiarlo.

## Criterios de Aceptación

- [ ] Un rubro base sin relaciones ni forks puede eliminarse definitivamente (`forceDelete()`); un fork puede eliminarse recursivamente aunque tenga hijos.
- [ ] Si tiene relaciones (categorías, servicios, órdenes en base o forks), no se permite la eliminación definitiva → debe desactivarse (HU-015).
- [ ] El fork personal puede eliminarse mediante `/api/user-catalog/...`, incluso con hijos, eliminando recursivamente el subárbol; la base queda intacta.
- [ ] La base solo puede eliminarse mediante admin/seeder y únicamente si no tiene forks ni relaciones.

## Notas / Dudas

- Para la base, `forceDelete()` requiere validar ausencia de relaciones y forks. Para un fork, la eliminación recursiva está permitida aunque tenga hijos.
