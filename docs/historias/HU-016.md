# HU-016 — Eliminar definitivamente rubro sin relaciones

**Épica:** Rubros, categorías y servicios
**Prioridad:** Media
**Estado:** Aprobada
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero eliminar definitivamente un rubro de mi catálogo personal que no tiene relaciones, para limpiarlo.

## Criterios de Aceptación

- [ ] Un rubro sin categorías, servicios ni órdenes (en base y forks) puede eliminarse definitivamente (`forceDelete()`).
- [ ] Si tiene relaciones (categorías, servicios, órdenes en base o forks), no se permite la eliminación definitiva → debe desactivarse (HU-015).
- [ ] Aplica tanto a rubro base como a fork personal (`user_catalog_items`).
- [ ] Eliminar fork personal → solo quita la copia del usuario; base intacta. Eliminar base → solo si 0 forks activos + 0 relaciones.

## Notas / Dudas

- Modelo híbrido: `SoftDeletes` trait → `forceDelete()` para hard delete real. **Validación previa:** check `categorias.count() + services.count() + order_services.count() + user_catalog_items.count() == 0`. UI: botón 'Eliminar' solo visible si pasa validación; si no → muestra 'Desactivar'.
