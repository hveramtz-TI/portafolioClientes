# HU-016 — Eliminar definitivamente rubro sin relaciones

**Épica:** Rubros, categorías y servicios
**Prioridad:** Media
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero eliminar definitivamente un rubro que no tiene relaciones, para limpiar mi catálogo.

## Criterios de Aceptación

- [ ] Un rubro sin categorías, servicios ni órdenes puede eliminarse definitivamente.
- [ ] Si tiene relaciones, no se permite la eliminación definitiva (debe desactivarse).
