# HU-019 — Desactivar categoría (oculta servicios, conserva historial)

**Épica:** Rubros, categorías y servicios
**Prioridad:** Media
**Estado:** Aprobada
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero desactivar una categoría de mi catálogo personal que tiene servicios u órdenes relacionadas, para ocultarla sin perder historial.

## Criterios de Aceptación

- [ ] Una categoría con servicios u órdenes relacionadas se desactiva (`status = 'desactivado'`), no se elimina físicamente.
- [ ] Al desactivarla, sus servicios dejan de mostrarse en el perfil público (scope `whereStatus('activo')`).
- [ ] El historial de órdenes se conserva intacto.
- [ ] La categoría puede reactivarse posteriormente (`status = 'activo'`).
- [ ] La base se desactiva solo mediante admin/seeder; el usuario propietario puede desactivar su fork mediante `/api/user-catalog/...`.
- [ ] El estado efectivo se calcula dinámicamente: categoría, base o padre fork desactivado bloquea la visibilidad de sus servicios.

## Notas / Dudas

- La eliminación definitiva de categorías sin relaciones se trata en HU-020.
- `status` es una columna dedicada (`activo`, `desactivado`); `overrides` no contiene status. Reactivar establece activo solo en el item seleccionado; no reactiva hijos desactivados ni vence un padre desactivado.
