# HU-044 — Agregar servicio existente a la orden (guarda copia histórica)

**Épica:** Órdenes de trabajo
**Prioridad:** Alta
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero agregar servicios existentes a una orden, para definir el trabajo a realizar.

## Criterios de Aceptación

- [ ] Se puede agregar un servicio existente del catálogo a la orden.
- [ ] La orden guarda una copia del título y valor del servicio al agregarlo.
- [ ] Un cambio posterior en el catálogo no modifica la orden.
