# HU-036 — Notificación push al usuario (PWA instalada y autorizada)

**Épica:** Solicitudes
**Prioridad:** Media
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero recibir una notificación push al llegar una solicitud, si tengo la PWA instalada y autorizada.

## Criterios de Aceptación

- [ ] Se envía notificación push si la PWA está instalada.
- [ ] Se envía solo si el usuario autorizó notificaciones.
- [ ] Si no está instalada o no autorizó, no se envía push (el email sigue aplicando).

## Notas / Dudas

- Depende del habilitador PWA (HU-001).
