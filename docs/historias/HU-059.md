# HU-059 — Redondeo de montos CLP a centena superior

**Épica:** Documento de Portafolio (PDF)
**Prioridad:** Media
**Estado:** Pendiente
**Fecha:** 2026-09-07

## Descripción

Como **freelancer**, quiero que los montos del PDF estén **redondeados hacia arriba a la centena superior**, para **no transparentar el monto real del contrato** y aun así comunicar el orden de magnitud del trabajo.

## Criterios de Aceptación

- [ ] Toda moneda mostrada en el PDF es **CLP** (sin multi-moneda).
- [ ] Cada monto impreso se calcula como `ceil(monto_real / 100) * 100`: redondeo **hacia arriba**, terminación en 00.
- [ ] Ejemplos validados: 1.453 → 1.500; 853.400 → 853.500.
- [ ] El monto redondeado **nunca es inferior** al valor real del snapshot.
- [ ] El redondeo aplica a cada monto visible en el PDF (por servicio y por total, si el diseño muestra totales).

## Notas / Dudas

- P2/RK3 de planning5: con montos grandes, la centena fija puede revelar precisión (1.000.000 → 1.000.100). Definir en SDD si el redondeo escala por magnitud.
