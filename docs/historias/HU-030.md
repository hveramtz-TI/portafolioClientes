# HU-030 — Carrito de servicios (multi-selección, una vez por servicio, quitar)

**Épica:** Perfil público
**Prioridad:** Media
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como visitante, quiero seleccionar varios servicios en un carrito, para solicitarlos juntos.

## Criterios de Aceptación

- [ ] Se pueden seleccionar varios servicios.
- [ ] Cada servicio se agrega una sola vez por solicitud.
- [ ] Se puede quitar un servicio del carrito.
- [ ] No hay selector de cantidad.
