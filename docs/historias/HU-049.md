# HU-049 — Solo lectura de órdenes Completada/Cancelada

**Épica:** Órdenes de trabajo
**Prioridad:** Alta
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero que las órdenes completadas o canceladas queden en solo lectura, para conservar el historial intacto.

## Criterios de Aceptación

- [ ] Una orden `Completada` es de solo lectura.
- [ ] Una orden `Cancelada` es de solo lectura.
- [ ] No se pueden editar servicios ni datos en esos estados.
