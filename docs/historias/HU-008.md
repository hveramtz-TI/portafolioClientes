# HU-008 — Listado de clientes con filtro activos/desactivados

**Épica:** Clientes y empresas
**Prioridad:** Alta
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero un listado de clientes que muestre activos por defecto y permita consultar desactivados, para mantener la pantalla limpia sin perder historial.

## Criterios de Aceptación

- [ ] El listado muestra clientes activos por defecto.
- [ ] Existe un filtro para ver clientes desactivados.
- [ ] El estado (`Activo` / `Desactivado`) es visible en cada registro.
- [ ] La búsqueda puede incluir clientes desactivados cuando corresponda.
