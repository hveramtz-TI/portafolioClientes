# HU-046 — Crear servicio desde la orden

**Épica:** Órdenes de trabajo
**Prioridad:** Media
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero crear un servicio nuevo directamente desde una orden, si no existe en el catálogo.

## Criterios de Aceptación

- [ ] Si no se encuentra un servicio, existe un botón para crearlo desde la orden.
- [ ] El servicio creado se agrega a la orden.
- [ ] El servicio creado queda disponible en el catálogo.
