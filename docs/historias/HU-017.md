# HU-017 — Crear categoría

**Épica:** Rubros, categorías y servicios
**Prioridad:** Alta
**Estado:** Aprobada
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero crear una categoría dentro de un rubro de mi catálogo personal, para agrupar servicios por tipo de solución.

## Criterios de Aceptación

- [ ] Se puede crear una categoría dentro de un rubro (base o fork personal).
- [ ] El nombre se expresa en lenguaje natural, orientado a la necesidad del cliente.
- [ ] La categoría se muestra disponible para asociarle servicios.
- [ ] El nombre es único dentro del rubro padre (`rubro_id + name` unique en tabla `categorias`).
- [ ] Si el rubro es un fork personal, la categoría se crea en el fork del usuario (`user_catalog_items`).

## Notas / Dudas

- Modelo híbrido: categoría vive en catálogo base global (`categorias` table) o en fork personal (`user_catalog_items`). Unicidad: `rubro_id + name` unique. FK `rubro_id` → `rubros.id`.
