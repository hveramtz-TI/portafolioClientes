# HU-017 — Crear categoría

**Épica:** Rubros, categorías y servicios
**Prioridad:** Alta
**Estado:** Aprobada
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero crear una categoría dentro de un rubro de mi catálogo personal, para agrupar servicios por tipo de solución.

## Criterios de Aceptación

- [ ] El usuario puede crear una categoría dentro de un rubro de su catálogo personal/fork.
- [ ] El nombre se expresa en lenguaje natural, orientado a la necesidad del cliente.
- [ ] La categoría se muestra disponible para asociarle servicios dentro del fork del usuario.
- [ ] El nombre es único dentro del rubro padre del catálogo personal.
- [ ] La categoría se crea como item personal en `user_catalog_items` (`base_id = null`), con su rubro fork como padre.
- [ ] La creación de categorías base pertenece a HU-024 (seeders/proceso administrativo), no a esta HU.

## Notas / Dudas

- El usuario no crea categorías globales: crea categorías personales en `user_catalog_items`, bajo un rubro fork. Las categorías base se cargan mediante seeders/proceso administrativo en HU-024.
