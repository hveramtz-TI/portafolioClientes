# HU-017 — Crear categoría

**Épica:** Rubros, categorías y servicios
**Prioridad:** Alta
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero crear una categoría dentro de un rubro, para agrupar servicios por tipo de solución.

## Criterios de Aceptación

- [ ] Se puede crear una categoría dentro de un rubro.
- [ ] El nombre se expresa en lenguaje natural, orientado a la necesidad del cliente.
- [ ] La categoría se muestra para asociarle servicios.
