# HU-039 — Vincular solicitud a cliente existente (sin duplicar)

**Épica:** Solicitudes
**Prioridad:** Media
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero vincular una solicitud a un cliente existente, para no crear duplicados.

## Criterios de Aceptación

- [ ] Si la combinación RUT + empresa ya existe, no se crea un cliente duplicado.
- [ ] La solicitud se vincula al cliente existente.
- [ ] El sistema muestra que ya existe un cliente coincidente.
