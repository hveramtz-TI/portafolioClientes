# HU-015 — Desactivar rubro (oculta servicios, conserva historial)

**Épica:** Rubros, categorías y servicios
**Prioridad:** Media
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero desactivar un rubro que tiene categorías, servicios u órdenes relacionadas, para ocultarlo sin perder historial.

## Criterios de Aceptación

- [ ] Un rubro con relaciones se desactiva, no se elimina físicamente.
- [ ] Al desactivarlo, sus categorías y servicios dejan de mostrarse en el perfil público.
- [ ] El historial de órdenes se conserva.
- [ ] El rubro puede reactivarse posteriormente.

## Notas / Dudas

- La eliminación definitiva de rubros sin relaciones se trata en HU-016.
