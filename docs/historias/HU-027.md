# HU-027 — Activar/desactivar perfil con confirmación

**Épica:** Perfil público
**Prioridad:** Media
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero activar o desactivar mi página pública, para controlar cuándo estoy disponible para recibir solicitudes.

## Criterios de Aceptación

- [ ] La página pública está desactivada inicialmente.
- [ ] Al activarla, se muestra una confirmación indicando que rubros, categorías y servicios serán visibles públicamente.
- [ ] El usuario puede activar y desactivar la página cuando lo necesite.
- [ ] Al desactivarla, deja de recibir nuevas solicitudes.
