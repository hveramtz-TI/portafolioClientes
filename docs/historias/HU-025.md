# HU-025 — Copia personalizable del catálogo por usuario (sin alterar la base)

**Épica:** Rubros, categorías y servicios
**Prioridad:** Alta
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero personalizar mi catálogo sin alterar la base precargada ni afectar a otros usuarios, para ajustar los servicios a mi caso.

## Criterios de Aceptación

- [ ] Cada usuario trabaja sobre una copia personalizable del catálogo.
- [ ] Editar, crear o eliminar en mi catálogo no modifica el catálogo base.
- [ ] Los cambios de un usuario no afectan a otros usuarios.
- [ ] Al seleccionar un rubro, el sistema asigna una copia de sus servicios por defecto.
