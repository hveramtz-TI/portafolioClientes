# HU-007 — Reactivar cliente

**Épica:** Clientes y empresas
**Prioridad:** Media
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero reactivar un cliente desactivado, para volver a usarlo sin crear un duplicado.

## Criterios de Aceptación

- [ ] Un cliente `Desactivado` puede volver a `Activo`.
- [ ] La reactivación se realiza desde el detalle o listado de desactivados.
- [ ] Al reactivar se revalida la unicidad RUT + empresa.
