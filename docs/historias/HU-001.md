# HU-001 — PWA responsive base (instalable, escritorio + mobile)

**Épica:** Plataforma
**Prioridad:** Baja
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero que la aplicación funcione como una PWA instalable y responsive, para poder usarla tanto en escritorio como en dispositivos mobile.

## Criterios de Aceptación

- [ ] La aplicación puede instalarse como PWA (manifest + service worker).
- [ ] El layout se adapta correctamente a escritorio y mobile.
- [ ] La aplicación puede usarse desde el navegador y desde la PWA instalada.
- [ ] Las notificaciones push pueden solicitarse cuando la PWA esté instalada (habilitador para HU-036).

## Notas / Dudas

- Los detalles técnicos de implementación (manifest, service worker, librería) se definen en SDD.
