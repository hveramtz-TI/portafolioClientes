# HU-038 — Convertir solicitud en cliente (un clic)

**Épica:** Solicitudes
**Prioridad:** Media
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero convertir una solicitud en cliente con una acción de un clic, si el cliente no existe.

## Criterios de Aceptación

- [ ] Si la combinación RUT + empresa no existe, se puede convertir la solicitud en cliente.
- [ ] La conversión se realiza con una acción de un clic.
- [ ] Solo el usuario puede crear clientes (el visitante no).
