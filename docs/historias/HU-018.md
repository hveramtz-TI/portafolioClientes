# HU-018 — Editar categoría

**Épica:** Rubros, categorías y servicios
**Prioridad:** Media
**Estado:** Aprobada
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero editar el nombre de una categoría de mi catálogo personal, para mantener actualizada mi organización de servicios.

## Criterios de Aceptación

- [ ] Se puede modificar el nombre de una categoría (base o fork personal).
- [ ] Se puede editar tanto una categoría precargada (base) como una propia (fork personal).
- [ ] Los cambios en categoría base se reflejan en servicios asociados y en forks de otros usuarios (si no tienen override).
- [ ] Al editar un fork personal (`user_catalog_items`), solo afecta la copia del usuario, no la base ni otros usuarios.
- [ ] El nuevo nombre mantiene unicidad dentro del rubro padre (`rubro_id + name` unique en `categorias` para base; `user_id + base_categoria_id` unique en forks).

## Notas / Dudas

- Modelo híbrido: editar base → propaga a forks sin override. Editar fork → aisla cambios. Unicidad validada en Request. FK `rubro_id` inmutable (no se cambia rubro padre al editar).
