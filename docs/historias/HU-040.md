# HU-040 — Crear orden desde solicitud con servicios modificables

**Épica:** Solicitudes
**Prioridad:** Media
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero crear una orden de trabajo desde una solicitud, con los servicios solicitados y poder modificarlos.

## Criterios de Aceptación

- [ ] Se puede crear una orden desde una solicitud.
- [ ] La orden se crea con los servicios solicitados.
- [ ] El usuario puede modificar los servicios antes de continuar.
- [ ] La orden queda vinculada a la solicitud y al cliente.
