# HU-028 — URL pública UUID inmutable + "Perfil temporalmente no disponible"

**Épica:** Perfil público
**Prioridad:** Media
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero una URL pública única y permanente para mi perfil, para compartirla de forma estable.

## Criterios de Aceptación

- [ ] La URL se genera automáticamente con un código único tipo UUID.
- [ ] La URL es inmutable y no puede modificarse.
- [ ] Si el perfil está desactivado, la URL muestra `Perfil temporalmente no disponible`.
- [ ] La URL desactivada no muestra un 404.
