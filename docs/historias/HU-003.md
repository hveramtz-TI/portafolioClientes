# HU-003 — Validar duplicado RUT + empresa con alerta

**Épica:** Clientes y empresas
**Prioridad:** Alta
**Estado:** Pendiente
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero que el sistema detecte clientes duplicados según RUT y empresa, para evitar registros repetidos.

## Criterios de Aceptación

- [ ] Mismo RUT sin empresa asociada ya existente → error y cancelación del guardado.
- [ ] Mismo RUT asociado a la misma empresa ya existente → error y cancelación del guardado.
- [ ] Mismo RUT asociado a una empresa diferente → permitido.
- [ ] La validación considera clientes activos y desactivados.
- [ ] Se muestra un mensaje de alerta claro al detectar el duplicado.

## Notas / Dudas

- La empresa se resuelve por su identificador, no solo por el nombre.
