## Descripción

Como usuario, quiero que el sistema precargue rubros, categorías y servicios comunes mediante seeders, para partir de una base lista.

## Criterios de Aceptación

- [ ] Existen seeders que precargan rubros, categorías y servicios comunes.
- [ ] Los servicios precargados tienen valores ficticios.
- [ ] El contenido se expresa en lenguaje natural.
- [ ] Los datos precargados sirven como punto de partida personalizable.
