# HU-024 — Seeders de rubros, categorías y servicios con valores ficticios

**Épica:** Rubros, categorías y servicios
**Prioridad:** Alta
**Estado:** Aprobada
**Fecha:** 2026-08-19

## Descripción

Como usuario, quiero que el sistema precargue un catálogo base de rubros, categorías y servicios comunes mediante seeders, para partir de una base lista y personalizable.

## Criterios de Aceptación

- [ ] Seeder `RubroSeeder` crea 3 rubros base: **Informática**, **Diseño**, **Consultoría**.
- [ ] Seeder `CategoriaSeeder` crea 7 categorías base asociadas a sus rubros (lenguaje natural).
- [ ] Seeder `ServiceSeeder` crea 12 servicios base con títulos, descripciones, valores CLP y tags técnicos.
- [ ] Valores ficticios en CLP enteros (ej: 300000, 450000, 800000, etc.).
- [ ] El contenido se expresa en lenguaje natural orientado a necesidades del cliente.
- [ ] Datos insertados en tablas base globales (`rubros`, `categorias`, `services`) con `status = 'activo'`.
- [ ] Al registrar usuario nuevo → no se clonan automáticamente; el usuario "selecciona" rubros (HU-025) para crear su fork personal.
